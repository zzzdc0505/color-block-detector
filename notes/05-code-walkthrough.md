## 2. `find_blocks()` 分三段读

### 第一段：准备（76–79 行）

```python
h, w = bgr.shape[:2]
hsv = cv2.cvtColor(bgr, cv2.COLOR_BGR2HSV)
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (7, 7))
img_area = float(h * w)
```

- `shape[:2]` 取高宽（第 1 课：shape 是"高, 宽, 通道"）；
- `kernel` 建在**循环外面**：7×7 的结构元素只有一份，反复用，别在循环里重复创建；
- `img_area` 只算一次：后面面积判断要用它做分母（面积**占比**，第 5 课）。

### 第二段：按色相分组 + 形态学（82–89 行）

```python
for name, ranges in HUE_CLASSES:
    mask = np.zeros((h, w), np.uint8)
    for lo, hi in ranges:
        mask |= cv2.inRange(hsv, (lo, 90, 45), (hi, 255, 255))
    if not mask.any():
        continue
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
```

四个"为什么"：

1. **为什么每个色相单独建掩膜？** —— 相邻色块贴着，一张掩膜会粘连（第 3 课，四格图第 2 格）。
2. **为什么 `mask = np.zeros(...)` 再 `|=`？** —— 红色跨 0 度，需要 `(0,9)` 和 `(170,180)` 两段，**用 `|=` 把两段并进同一张掩膜**。
3. **为什么 `if not mask.any(): continue`？** —— 这一格要是全黑（比如图里没有紫色），后面的形态学和轮廓都是白算，直接跳过。省时间，也顺手避开空图。
4. **为什么先 CLOSE 再 OPEN？** —— 先补洞保证色块完整（面积/矩形度才准），再去噪保证色块独立（轮廓个数才对）；而且**开运算不可逆**（第 4 课）。

### 第三段：轮廓 + 三关过滤（91–103 行）

```python
for cnt in cv2.findContours(mask, cv2.RETR_EXTERNAL,
                            cv2.CHAIN_APPROX_SIMPLE)[-2]:
    area = cv2.contourArea(cnt)
    if not (min_area_ratio * img_area <= area <= max_area_ratio * img_area):
        continue

    (cx, cy), (rw, rh), angle = cv2.minAreaRect(cnt)
    if rw < rh:
        rw, rh, angle = rh, rw, angle + 90.0
    if rh < 1.0 or rw / rh < aspect_min:
        continue
    if area / (rw * rh) < fill_min:
        continue
```

- `[-2]` 这个下标：`findContours` 返回 `(contours, hierarchy)`，取第二个才是轮廓列表。不同 OpenCV 版本返回个数不一样，`[-2]` 稳定拿到轮廓；
- 三关的顺序：**面积 → 长宽比 → 矩形度**，便宜的在前、贵的（要算 minAreaRect）在后（第 5 课）；
- `if rw < rh: 交换` —— `minAreaRect` 不保证长边是 w，不归一化竖块会被误杀（第 5 课）；
- `if rh < 1.0` 这一小段是**防除零**：理论上矩形高不会是 0，但退化轮廓（一条线）真会，除以 0 就崩。

### 第四段：判色（105–111 行）—— 全文件最"细"的四行

```python
box = cv2.boxPoints(((cx, cy), (rw, rh), angle)).astype(np.int32)

patch = np.zeros((h, w), np.uint8)
inner = cv2.boxPoints(((cx, cy), (rw * 0.4, rh * 0.4), angle))
cv2.fillPoly(patch, [inner.astype(np.int32)], 255)
mean_bgr = np.array(cv2.mean(bgr, mask=patch)[:3])
```

- **为什么不用 `bgr[y1:y2, x1:x2]` 直接切片？** 因为色块是**旋转**的，正矩形切片会把背景切进来；`fillPoly` 能画**任意四边形**的掩膜，跟着色块转。
- **为什么只取中心 40%？** 边缘有黑描边、抗锯齿、环境反光；取整块均值会被污染（第 2 课）。
- **为什么是"均值"而不是"取一个点"？** 单点会被噪点带偏，均值更稳。
- `cv2.mean(bgr, mask=patch)` 里的 `mask` 是"只统计白色区域"，这又是掩膜的老套路（第 3 课）。

## 3. 破坏性实验：拆掉任何一根柱子，房子就塌

`l7_break_it.py` 不改源码，只把参数换成坏值：

| 改动            | 块数 | 输出                                      | 说明                         |
| --------------- | ---- | ----------------------------------------- | ---------------------------- |
| 基准            | 6    | 红 绿 红 蓝 绿 蓝                         | 正确答案                     |
| 拆掉长宽比      | 7    | 红 绿 红 蓝 绿 蓝 **橙**                  | 花盆（aspect 1.20）混进来    |
| 拆掉矩形度      | 8    | **黄** 红 绿 红 蓝 绿 蓝 **橙**           | 地面（矩形度 0.54）混进来    |
| 拆掉面积下限    | 14   | 红 绿 红 蓝 绿 蓝 蓝 橙 橙 橙 橙 黄 红 黄 | 小噪点全变成"色块"           |
| 拆掉面积上限    | 6    | 红 绿 红 蓝 绿 蓝                         | **没变化**                   |
| 面积下限调到 2% | 0    | （空）                                    | 真色块最大才 1.86%，全被误杀 |
| 长宽比调到 2.0  | 5    | 红 绿 红 蓝 绿                            | 蓝色块 1.92 被误杀           |

**两个值得注意的点：**

1. "拆掉矩形度"那行，**不仅多出块，顺序也被带偏了**（黄色地面跑到了第一位）——
   因为混进来的大块改变了 x 聚列的边界，连带把读序弄乱。**一个阈值失效会连锁影响下一步**，这句面试能讲。
2. "拆掉面积上限"**没有变化** —— 因为这张图上最大的候选（地面 4.39%）远小于上限 15%，
   这个条件被更严的**矩形度**挡住了。**参数在这份数据上是冗余的，但不代表它没用**（换场景可能用得上）。
   能主动说出"这个参数在当前数据上其实没起作用"，比假装每个参数都至关重要可信得多。
